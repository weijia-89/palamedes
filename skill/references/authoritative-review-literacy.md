# Authoritative review literature

Load when: **systematic review**, **meta-analysis**, **meta-review**, **scoping review**, **narrative survey**, or paper cited as "authoritative" for policy/routing/canon.

Scope: grade and **tear down** review papers — not PRISMA protocol design unless asked.

---

## §STUDY-TYPE — classify before key findings

| Type | Tier if well-done | Does **not** prove |
|------|-------------------|---------------------|
| Quantitative meta-analysis | T1 for pooled effect in included studies | Your deployment; future behavior |
| Systematic review | T1–T2 for evidence landscape | Effect precision without MA sub-component |
| Meta-review / review of reviews | T2 for failure-mode taxonomy | Pooled magnitudes; often snowball not PRISMA |
| Scoping review | T2 for breadth map | Strong causal/magnitude claims |
| Narrative survey | T2 for methods index | Model rank order; single-benchmark validity |
| Controlled empirical | T1 for that experiment | Beyond experimental matrix |
| Position / framework | T2 concepts; T1 if validated empirically | Prevalence without their data |

**Iron law:** meta-review ≠ meta-analysis — never treat taxonomy papers as pooled effect-size evidence.

## §AUTH-1 — checklist (Y/N/Partial/Unknown each)

| ID | Criterion |
|----|-----------|
| A-1 | Search documented OR snowball seed + trace declared |
| A-2 | Inclusion/exclusion pre-specified or post-hoc labeled |
| A-3 | Primary vs secondary distinguished |
| A-4 | Quality appraisal of included studies |
| A-5 | Heterogeneity addressed or "narrative only" stated |
| A-6 | Publication bias if meta-analysis |
| A-7 | Funder / COI declared |
| A-8 | Review claims vs primary evidence separated |
| A-9 | Limitations name selection/language/grey-lit bias |
| A-10 | LLM/benchmark: contamination, construct validity, protocol heterogeneity |

**AUTH-G1:** ≥4 N → `[review-weak]` — hypothesis generation only, not load-bearing routing policy.

---

## §META-1 — only if paper pools effects

Require: effect metric, CI, k, fixed/random justification, sensitivity, protocol/preregistration or `[inferred:post-hoc]`. Missing → no headline %.

## §SNOW-1 — meta-review class

Snowball OK for critique synthesis; not PRISMA-exhaustive. No MA claimed → forbid pooled-effect inference. Interdisciplinary reviews: verify CS claims separately.

## §ROUTING-1 — reviews vs routing

| Type | Safe | Unsafe |
|------|------|--------|
| Meta-review | Failure-mode checklist for private eval | Global model order from cited leaderboards |
| Systematic (contamination) | Require contamination checks in harness | Trust any public benchmark named |
| Construct validity SR | Filter benchmarks by checklist | Venue = validity |
| Controlled empirical | Negative result in paper's matrix | Extrapolate to all benchmarks |
| Survey catalog | Shortlist eval dimensions | Pick model from survey tables |

Reviews explain why public benches are weak priors — they do not replace private eval.

## §CITE-1 — tag shape

`[T*-verified, read:body, study-type:<type>, COI:<none|funder>]` — tier must match §STUDY-TYPE (meta-review → T2, not T1).
